# Готовые промпты для генерации 2D-ассетов

Спутник [ART_TZ_2D.md](ART_TZ_2D.md): там обоснование и приёмка, здесь — текст
для копирования. Каждый промпт самодостаточен, канон стиля и техтребования уже
внутри. **Один промпт — одна генерация, ничего не дописывать.**

Порядок в файле = порядок заказа. Первые три закрывают всё, что видно
в каждом кадре боя.

> ⚠️ **Перед следующим заказом решить: славяне или западное средневековье.**
> Половина референсов в `Assets/ART/References` — славянское тёмное фэнтези
> (тролль, нежить, ведьма, волк, «SLAVIC KING»), а уже сделанные иконки —
> западные: геральдический лев, топфхельм с крестом, щит крестоносца.
> Разбор и рекомендация — в [ART_REFERENCES.md](ART_REFERENCES.md).
>
> Если идём в славянское, перезаказать надо **один лист**: шлем на шелом
> с бармицей, щит на червлёный с умбоном, льва на монете на медведя.
> Череп, ратуша, постройки и ветки прокачки нейтральны и остаются.
>
> Плюс в очередь добавляются **знамёна фракций** (красное людям, фиолетовое
> нежити, коричневое зверям — цветовой код троп из референсного скриншота)
> и **иконки типов отрядов** для панели найма.

## 1. Иконки ресурсов и счётчиков

Чинит вишенку на счётчике армии, вишенку на счётчике врагов и бревно на опыте.

```
Нарисуй набор иконок для интерфейса средневековой игры.

СТИЛЬ. Стилизованная средневековая графика в духе low-poly-рендера: крупные
простые формы, плоская заливка с мягкими гранями. Без фотореализма, без
мультяшной обводки, без пиксель-арта. Тёплый закатный свет, источник сверху
слева под 45 градусов. Материалы читаются цветом и силуэтом, а не мелкими
деталями. Настроение — обжитая крепость на краю тёмного леса: дерево, кованое
железо, потёртое золото, красная геральдика.

ПАЛИТРА. Тёмно-коричневый #2B211E, кант #6B4A2F, золото #C9A227,
кремовый #F2E4C8, тревожно-красный #C0392B, зелёный #6A9E3F, синий #3B6FA0.

РАСКЛАДКА. Одно изображение 1536x1024, сетка 3 колонки на 2 ряда, ячейка
512x512. Каждый предмет строго по центру своей ячейки, поля 8-10 процентов.
Никаких разделительных линий, рамок, подписей и номеров. Между ячейками
пустота. Порядок слева направо, сверху вниз.

СОДЕРЖИМОЕ ЯЧЕЕК.
1. Горка из трёх золотых монет с львиным профилем, вид три четверти сверху.
2. Рыцарский шлем-топфхельм с красным плюмажем, вид в три четверти.
3. Рогатый череп чудовища, тёмный, с холодным подсветом.
4. Королевская корона с красными камнями, вид спереди чуть сверху.
5. Маленькая ратуша с флагом на крыше, обобщённый силуэт.
6. Круглый щит с трещиной, красный акцент.

ОБЯЗАТЕЛЬНО. Фон полностью прозрачный. Если прозрачность недоступна — ровный
однотонный фон #FF00FF без градиента и без теней на фоне. Никакого текста,
цифр и букв. Никаких падающих теней за пределами предмета. Никаких подложек,
кругов и рамок под иконками. Формы толстые: иконка должна читаться в 32
пикселя. Одинаковый визуальный вес у всех шести.

Формат PNG.
```

## 4. Рамки, кнопки и полоски

Самый рискованный промпт: генератор плохо держит ровные рамки. Требования
внутри жёстче обычного — из этих картинок делается 9-slice.

```
Нарисуй элементы интерфейса средневековой игры: рамки и полоски.

СТИЛЬ. Стилизованная средневековая графика: дерево, кованое железо, потёртое
золото. Плоская заливка с мягкими гранями, без фотореализма и без мультяшной
обводки. Свет сверху слева.

ПАЛИТРА. Заливка панели #2B211E, кант и оковка #6B4A2F, золотой акцент
#C9A227, зелёный #6A9E3F для заливки полоски.

РАСКЛАДКА. Одно изображение 1536x1024, сетка 3 колонки на 2 ряда, ячейка
512x512. Каждая форма занимает свою ячейку целиком, без полей. Без
разделительных линий, подписей и номеров. Порядок слева направо, сверху вниз.

СОДЕРЖИМОЕ ЯЧЕЕК.
1. Панель интерфейса: тёмная скруглённая плашка с тонким золотым кантом.
2. Кнопка в обычном состоянии: та же плашка меньшей высоты, кант золотой,
   лёгкий объём.
3. Кнопка при наведении: та же форма, кант ярче, заливка на тон светлее.
4. Слот способности: квадратная рамка со скруглением и коваными уголковыми
   накладками по четырём углам.
5. Жёлоб полоски: узкая горизонтальная выемка, тёмная, с тонким кантом.
6. Заливка полоски: та же узкая горизонтальная форма, ровный зелёный цвет.

КРИТИЧНО ДЛЯ ЭТОГО НАБОРА. Каждая форма строго фронтально, вид прямо, без
перспективы, без наклона и без поворота. Все четыре угла каждой формы
одинаковые и зеркально симметричные. Толщина канта постоянна по всему
периметру. Центр каждой формы — ровная однотонная заливка без градиента,
бликов, текстуры, узора и рисунка. Центр будет растягиваться программно,
любой градиент или узор даст полосы.

ОБЯЗАТЕЛЬНО. Фон вокруг формы полностью прозрачный, иначе ровный #FF00FF.
Никакого текста и цифр. Никаких теней за пределами формы.

Формат PNG.
```
