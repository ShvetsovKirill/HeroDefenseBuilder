# Референсы

Исходники, из которых нарезается арт. Готовые спрайты игры лежат
не здесь, а в `Assets/ART/Sprites`.

## Папки

| Папка | Что внутри |
|---|---|
| `01_Promo` | обложка, логотип, эмблема — то, что увидит игрок в магазине |
| `02_Concept` | дизайн-листы, мокапы экранов, концепты меню и замка |
| `03_Characters` | листы персонажей для моделирования и карточки юнитов |
| `04_UI` | листы иконок, кнопок и рамок — исходники нарезки |
| `05_Campaign` | арт слоя кампании: владения, командиры, фракции, фон карты |
| `Storozha` | арт воина «Сторожа» с отдельной ветки |

## Именование

`Категория_Что_Вариант.расширение` — латиницей, без пробелов и дат.

Примеры: `KeyArt_Clean`, `Logo_Emblem`, `Icons_Rewards`,
`MapBackground_Parchment`, `Sheet_Undead`.

Суффикс `_alt` — другая версия того же заказа, оставленная для сравнения:
`Buttons_Round` и `Buttons_Round_alt` это один набор от разных моделей.
Суффикс `_gpt` / `_nano` — тот же промпт у разных генераторов.

**Имена от генератора не сохраняем.** «ChatGPT Image 6 сент. 2026 г.,
13_29_12.png» ничего не говорит о содержимом, ломает консоль кириллицей
и не сортируется. Файл переименовывается сразу при укладке.

## Как класть новое

Свежие листы кидай в корень `References` — я разберу их при следующем
заходе: опознаю, переименую и разложу по папкам.

Перекладывать надо **через редактор** (`AssetDatabase.MoveAsset`), а не
проводником: иначе теряются `.meta`, а вместе с ними ссылки в сценах.
